# license-active

软件许可证激活客户端。用于在设备上完成软件许可证的激活

## 功能特性

- **在线激活**：输入许可证密钥，客户端自动完成「查询许可证 → 绑定当前设备 → 签发令牌 → 本地验证入库」的完整流程；
- **离线激活**：适用于无法访问许可证服务的环境，粘贴服务端预先签发的离线令牌，客户端在本地完成签名与设备指纹校验后激活。
- **取消激活**：在线激活会调用服务端解绑设备席位并清除本地令牌；
- **设备指纹绑定**：基于操作系统、CPU 架构、平台机器标识与主机名计算 SHA-256 指纹，令牌与设备一一对应，换机即失效。
- **本地持久化与会话恢复**：激活数据与签名公钥存于本地 SQLite 数据库；每次启动重新计算指纹并复验令牌，过期或校验失败的激活会被自动清除并提示重新绑定。

### 配置

复制 `.env.example` 为 `.env`，修改：

```env
LICENSE_API_URL=http://139.199.182.155:443
```

| 变量 | 说明 | 默认值 |
| --- | --- | --- |
| `LICENSE_API_URL` | 许可证服务地址 | `http://139.199.182.155:443` |

### 运行与构建

```bash
# 开发运行
cargo run

# 发布构建
cargo build --release

# 运行测试
cargo test
```

## 使用说明

1. 启动应用后，在「在线激活」页输入许可证密钥，点击「激活许可证」；或在「离线激活」页粘贴离线令牌。
2. 激活成功后，应用会展示当前许可证的密钥、令牌有效期、许可证到期时间、激活时间及授权功能列表。
3. 如需释放设备席位，点击「取消激活」：在线激活会同步解绑服务器，离线激活仅清除本地令牌。
